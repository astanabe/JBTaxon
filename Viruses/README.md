## 補足

- ICTV がウイルス種名に二名法を導入したため種名から系統名を判断しにくくなったことを受け、日本ウイルス学会ウイルス命名作業部会が重要なウイルスに和名を付けたもの。
- **和名の列名が2ファイルで異なる。** 植物・藻類・菌類のファイルは `ウイルス和名`、ヒト動物のファイルは `和名`。`generate_tables.pl` はヘッダ行から列を決めるのでどちらでも読める。
- Realm から Genus までの列はラテン名だけで和名がないため、**出力に寄与するのは種の行だけ**である。和名を持つ行は2ファイル合計で約1,650行。
- `jsv.umin.jp` に robots.txt はない (HTTP 404)。
