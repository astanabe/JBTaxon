# 哺乳類 (Mammals)

日本哺乳類学会「世界哺乳類標準和名リスト2021年度版」を使用する。**日本産ではなく世界の哺乳類を対象としたリスト**である（配布ページの名称は「哺乳類標準和名リスト」だが、Excel のシート名が「世界哺乳類標準和名リスト2021年度版」であり、内容も世界の全哺乳類 5,523 種を収録している）。

## 自動ダウンロードされるファイル

なし。利用規約への同意が必要なため `fetch_data.pl` の対象外。

## 手動で配置するファイル

| ファイル | 内容 | 取得先 |
|---|---|---|
| `list_20211223.zip` | `list_20211223.pdf` と `list_20211223.xlsx` を含む書庫 | https://www.mammalogy.jp/list/index.html |

上記ページで利用規約に同意した上でダウンロードし、このディレクトリに置く。**配布されている zip ファイルのままで構わない（zip は自動的に展開される）。**

## 補足

- zip の中身は `list_20211223/` ディレクトリ配下に PDF と Excel が入っている。**`generate_tables.pl` が自動的に展開し、Excel の方だけを使う**（PDF は同内容だが列の桁位置がページごとに変動するため使わない）。
- Excel はヘッダが2行（縦結合）でデータは3行目から。5,526行目以降は A〜T 列が空の付録ブロック（1,288行）なので除外する。U〜W 列（MSW3 / CMW / MDD1.6 の学名）が採用学名と異なる場合は学名シノニムとして扱う。
- 同意ゲートは Vue.js によるクライアントサイド判定のみで技術的には自動取得できてしまうが、**規約遵守上の判断として手動配置とする**。
- 規約は再配布と改変物の出版を禁止しているが、同意してダウンロードした本人が加工して自分で使うことは禁じていない。加工プログラムしか含まない JBTaxon とは衝突しない。
- **出典明記が求められる情報源**。成果物に出典・引用表記を含めること。

## 注意

このディレクトリ内の生データファイルは**リポジトリにコミットしないこと**。情報源の一部は改変・再配布が禁止されており、JBTaxon が配布するのは生成用スクリプトだけである。
